# 나경이 일기 💗

여자친구와의 하루하루를 기록하는 개인용 앱입니다.
깃허브 페이지(GitHub Pages)에 올린 뒤, 휴대폰·태블릿 홈 화면에 앱으로 설치해서 씁니다.

- 기록: 날짜 + 기분 + 제목 + 장소 + 글 + 사진 여러 장
- 달력: 날짜마다 기념일과 기록 사진이 보임
- 기념일: 100일·주년 자동 계산, 생일, 가족 생일, 커플 데이, 직접 만든 기념일
- 그녀 정보: 기본 정보, 사이즈, 좋아하는 것, 못 먹는 것, 가족, 갖고 싶어하는 것, 나만의 항목
- 교대 근무표: 데이(D)·이브닝(E)·나이트(N)·오프(O), 근무표 사진을 Claude가 읽어서 한 번에 입력
- 백업/불러오기, 비밀번호 잠금, 다크 모드, 인터넷 없이 실행

> 🔒 **기록·사진·그녀 정보는 깃허브에 올라가지 않습니다.**
> 깃허브에는 앱 코드만 올라가고, 기록은 앱을 쓰는 기기 안에만 저장됩니다.

## 1. 깃허브에 올릴 파일 (6개)

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 동작 전부 |
| `sw.js` | 인터넷 없이도 앱이 열리게 해 줌 (서비스 워커) |
| `manifest.json` | 앱 이름·아이콘 등 설치 정보 |
| `icon-192.png` | 앱 아이콘 (작은 것) |
| `icon-512.png` | 앱 아이콘 (큰 것) |
| `icon-maskable-512.png` | 안드로이드 둥근 아이콘용 |

`README.md`(이 설명서)와 `PROMPT.md`(기획서)는 같이 올려도 되고 안 올려도 됩니다.

## 2. 깃허브에 등록하기 (처음 한 번)

1. 받은 `our-days-github.zip` 파일의 **압축을 풉니다.**
   - 갤럭시 태블릿: **내 파일** 앱 → 다운로드 → zip 파일 길게 누르기 → **압축 풀기**
2. 인터넷 브라우저에서 **https://github.com** 에 들어가 로그인합니다.
3. 오른쪽 위 **＋** 버튼 → **New repository** (새 저장소)를 누릅니다.
4. 다음처럼 입력합니다.
   - **Repository name**(저장소 이름): `our-days`
   - **Public**(공개) 선택 — 무료 깃허브 페이지는 공개 저장소에서만 됩니다. 공개되는 것은 앱 코드뿐입니다.
   - 아래쪽 **Create repository** 버튼을 누릅니다.
5. 새 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
6. **choose your files** 를 누르고, 1번에서 압축을 푼 폴더의 **파일 6개**를 모두 선택합니다.
   - 폴더째 올리지 말고, 파일들만 올려야 합니다.
7. 맨 아래 초록색 **Commit changes** 버튼을 누릅니다.
8. 저장소 위쪽 메뉴의 **Settings**(설정) → 왼쪽 메뉴의 **Pages** 를 누릅니다.
9. **Build and deployment** 에서
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` 과 `/ (root)` 선택 → **Save**
10. 1~3분 기다린 뒤 새로고침하면 위쪽에 주소가 나옵니다.
    - 주소 모양: `https://내아이디.github.io/our-days/`

## 3. 앱으로 설치하기

**처음 설치할 때 쓴 브라우저를 계속 써야 합니다.** (기록이 그 브라우저 안에 저장되기 때문)

### 갤럭시 / 안드로이드 — 크롬(Chrome)
1. 크롬에서 위 주소를 엽니다.
2. 앱 첫 화면 또는 설정 화면의 **설치** 버튼을 누르거나,
   오른쪽 위 **⋮** → **홈 화면에 추가** (또는 **앱 설치**) 를 누릅니다.
3. 홈 화면에 생긴 **나경이 일기** 아이콘으로 엽니다.

### 갤럭시 — 삼성 인터넷
1. 삼성 인터넷에서 주소를 엽니다.
2. 아래쪽 **≡** 메뉴 → **현재 페이지 추가** → **홈 화면** 을 누릅니다.

### 아이패드 / 아이폰 — 사파리(Safari)
1. 사파리에서 주소를 엽니다.
2. **공유** 버튼(네모에 위쪽 화살표) → **홈 화면에 추가** 를 누릅니다.

## 4. 처음 사용하기

1. 앱을 열면 **그녀 이름, 사귄 날, 그녀 생일, 내 이름** 을 묻습니다. (나중에 설정에서 바꿀 수 있어요)
2. 오른쪽 아래 **＋** 버튼(태블릿은 왼쪽 **새 기록**)으로 기록을 남깁니다.
3. **그녀** 탭에서 정보를 채웁니다. 가족 생일을 적으면 달력에 표시됩니다.
   - **기본 정보·사이즈**: 채우고 싶은 줄(예: 키)을 누르면 그 칸만 입력하는 창이 떠요. 입력하고 **저장** (키보드의 완료 버튼도 돼요).
   - **좋아하는 것**: 아래쪽 **＋ 음식** 같은 버튼(또는 오른쪽 위 **등록**)을 누름 → 종류 확인 → 이름 입력 → **등록**.
     창이 그대로 있으니 떡볶이 → 등록, 마라탕 → 등록 … 이렇게 이어서 넣고, 다 했으면 **닫기**.
   - 등록한 것을 누르면 고치거나 지울 수 있어요. **싫어하는 것·못 먹는 것** 도 같은 방법이에요.
4. **기념일** 탭에서 첫 데이트 같은 우리만의 날을 추가합니다.
   - 음력 생일은 자동 변환이 안 되니, "한 번만"으로 해마다 그 해 양력 날짜를 추가해 주세요.

## 5. 교대 근무표 넣기

근무표 화면은 **달력 아래 "○○ 근무표"**, 홈의 **근무 카드**, 설정의 **근무표 입력** 버튼으로 열어요.

### 방법 1 — 사진을 Claude가 읽게 하기 (한 달을 한 번에)
1. 근무표 화면 위쪽 **🤖 사진 속 근무표 자동으로 읽기** 를 누릅니다.
2. **부탁 문장 복사** 를 누릅니다. (그녀 이름·달·기호가 들어간 문장이 복사돼요)
3. **Claude 열기** 를 누릅니다.
4. Claude에서 **＋** 버튼으로 근무표 사진을 첨부하고, 입력칸을 길게 눌러 **붙여넣기** → 보내기.
   - 그녀 이름 줄과 날짜 줄만 잘라서 보내면 더 정확해요.
5. Claude 답 아래의 **복사** 버튼을 누릅니다.
6. 앱으로 돌아와 **붙여넣기** → **근무표에 넣기** 를 누릅니다.
7. 들어간 칸에는 작은 점이 표시돼요. 사진과 비교해 보고 틀린 곳은 고친 뒤 **저장** 을 누릅니다.

### 방법 2 — 직접 누르기
1. 첫날(예: 1일)을 누릅니다.
2. 근무표를 보면서 **D · E · N · O** 버튼을 차례로 누릅니다. 누를 때마다 다음 날로 넘어가요.
3. 틀리면 **되돌리기**, 비우려면 **이 날 지우기** → 끝나면 **저장**.

- 근무표 화면의 **근무표 사진 보관하기** 로 원본 사진을 달마다 저장해 둘 수 있어요.
- **근무 시간은 병원마다 달라요.** 설정 → 💼 근무표 에서 데이·이브닝·나이트를 눌러 실제 시간으로 고쳐 주세요.
- 휴가·미들 같은 근무는 **근무 종류 추가** 로 만들 수 있어요. ("쉬는 날"을 켜면 다음 쉬는 날 계산에 들어가요)

## 6. ⚠️ 꼭 알아 둘 것 — 백업

- 기록은 **그 기기, 그 브라우저 안에만** 저장됩니다.
- 이럴 때 기록이 **사라질 수 있습니다**:
  - 브라우저의 "인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터" 를 지울 때
  - 브라우저 앱을 지우거나 기기를 초기화할 때
  - 기기를 바꿀 때
- 그래서 **한 달에 한 번쯤 설정 → 백업 파일 저장** 을 눌러 주세요.
  - `나경이일기-백업-날짜.zip` 파일이 생깁니다. (예전 백업 `our-days-backup-날짜.zip` 도 그대로 불러올 수 있어요)
  - 이 파일을 구글 드라이브, PC, 카카오톡 "나에게 보내기" 등에 보관하세요.
  - **압축을 풀지 말고 zip 그대로** 보관하세요.
  - **백업 파일을 깃허브에 올리면 안 됩니다** (공개 저장소라 누구나 볼 수 있어요).
- 30일 넘게 백업하지 않으면 홈 화면에 알림이 나옵니다.

### 새 기기로 옮기기
1. 새 기기에 앱을 설치합니다.
2. 첫 화면 아래 **백업 파일 불러오기** 를 누르고 zip 파일을 고릅니다.

### 태블릿과 휴대폰 둘 다 쓰기
자동으로 맞춰지지는 않습니다. 한쪽에서 백업 → 다른 쪽에서 **불러오기 → 합치기** 를 하면 두 기기의 기록이 합쳐집니다.
(가능하면 기록은 한 기기에서 주로 쓰는 것을 추천합니다.)

## 7. 잠금

설정 → 잠금 → **잠금 켜기** 에서 숫자 4자리 비밀번호를 만들 수 있습니다.
- 앱을 열 때, 그리고 다른 앱에 1분 넘게 있다가 돌아올 때 비밀번호를 묻습니다.
- 비밀번호를 잊으면 잠금 화면의 **비밀번호를 잊었어요** → **사귄 날짜** 를 입력하면 풀립니다.
- 기록을 암호화하는 기능이 아니라, 다른 사람이 화면을 보지 못하게 가리는 기능입니다.

## 8. 앱을 고쳤을 때 (업데이트)

1. 고친 파일을 **나경이 일기 저장소(our-days)** 에서 **Add file → Upload files** 로 다시 올립니다. (같은 이름이면 덮어써집니다)
   - UTA STUDY 같은 다른 앱의 저장소에 올리지 않도록 저장소 이름을 꼭 확인하세요.
2. **Commit changes** → 1~3분 기다립니다.
3. 앱의 **설정 → 새 버전 받기 → 새로고침** 을 누릅니다.
4. 설정 화면의 **앱 버전** 숫자가 바뀌었는지 확인합니다.
   - 고칠 때는 `index.html` 안의 `APP_VERSION` 과 `sw.js` 안의 `VERSION` 숫자를 똑같이 올려 주세요.

기록은 업데이트해도 지워지지 않습니다.

## 9. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 깃허브 주소가 404로 나옴 | Pages 설정 후 몇 분 기다리기 / 파일이 폴더 안이 아니라 저장소 맨 위에 있는지 확인 |
| "저장 공간을 열 수 없어요" | 시크릿(비공개) 모드에서는 안 됩니다. 일반 창에서 여세요 |
| 사진이 안 들어감 | 아이폰의 HEIC 사진 등 일부 형식은 크롬에서 열 수 없어요. JPG로 바꿔서 넣어 주세요 |
| 설치 버튼이 안 보임 | 크롬 ⋮ 메뉴의 "홈 화면에 추가"를 쓰세요 |
| 기록이 안 보임 | 처음 설치한 브라우저와 다른 브라우저로 열었는지 확인하세요 |
| 휴대폰에서 화면이 확대돼 보임 | 화면 폭이 좁게 잡히는 휴대폰은 자동으로 살짝 줄여서 보여 줘요(설정 → 앱 정보 → **화면 맞춤** 에서 확인). 그래도 크게 보이면 크롬 ⋮ → 설정 → 접근성 → **확대/축소** (크롬 버전에 따라 **텍스트 크기 조정**) 가 100%인지 확인하세요 |
| 화면이 저절로 커졌다 작아짐, 아래 메뉴가 사라짐 | v1.2.1에서 고쳤어요. 설정 → 앱 정보에서 버전이 v1.2.1 이상인지 확인하세요. 앱 전체를 두 손가락으로 확대하는 기능도 꺼 두었어요(사진 크게 보기에서의 확대는 그대로 돼요) |
| "이미 설치되어 있다"고 나옴 | 같은 깃허브 주소 아래의 다른 앱(UTA STUDY 등)과 겹친 경우예요. 두 앱의 주소를 Claude에게 알려 주면 함께 설치되게 고칠 수 있어요 |
| Claude 답을 붙여넣었는데 "읽을 수 있는 근무가 없어요" | Claude 답의 복사 버튼으로 답 전체를 복사했는지 확인하세요. `근무표 2026-11` 다음 줄부터 `1 D` 모양이면 돼요 |
